## 3. Algorithms

### Breadth-First Search (BFS)

BFS stores states in a FIFO queue using `deque`. Each processed state increments `nodes_expanded`. When the goal is found, the parent dictionary is used to reconstruct the path. fileciteturn0file1L24-L55

### Depth-First Search (DFS)

DFS uses an explicit stack and a visited set. It is depth-limited to 30 to prevent excessive exploration. The parent dictionary is again used to reconstruct the solution path. fileciteturn0file1L58-L93

## 7. Analysis

For this particular start state, BFS reaches the goal after two moves and therefore stops after expanding only three states. The report explains that BFS explores the state space level by level, giving the shortest path for this unweighted puzzle. fileciteturn0file0L32-L40

DFS follows one branch deeply before backtracking. In this experiment, that caused it to explore many more states before reaching the goal, producing a much longer 22-move solution. fileciteturn0file0L35-L40

The code implements the two different frontier strategies directly:

```python
# BFS
state = frontier.popleft()

# DFS
state, depth = stack.pop()
```

These operations are visible in the submitted program. fileciteturn0file1L33-L37 fileciteturn0file1L69-L76

## 8. Complexity / Theory Connection

For an unweighted search problem such as the 8-puzzle, BFS is complete and finds a shortest solution when a solution exists, provided the usual finite-state assumptions apply.

DFS generally uses less frontier memory, but it does not guarantee a shortest solution. The report also notes that BFS memory can grow quickly as the problem becomes larger, while DFS may spend more time exploring irrelevant branches. fileciteturn0file0L39-L46

## 9. Conclusion

The experiment demonstrates how theoretical properties of search algorithms appear in actual program measurements. For the selected 8-puzzle instance, BFS required only 3 expanded nodes and returned a 2-move solution, while DFS expanded 17,742 nodes and returned a 22-move solution. fileciteturn0file0L54-L61

The main lesson is that the choice of search strategy can significantly affect both execution effort and solution quality.
